TRADUÇÃO PT-BR DO HARVESTER (versão Steam)
==========================================

O que vem nesta pasta
---------------------
HARVEST\DIALOG.RSP              -> opções de resposta e tópicos de conversa
HARVEST\MENU.INI                -> menu principal e de opções
HARVEST\HARVEST.EXE             -> ações do mouse ("Examine", "Pegue"...), pausa, etc.
HARVEST_CD\HARVESTER_DISC1.ISO  -> disco 1 com falas e textos traduzidos
HARVEST_CD\HARVESTER_DISC2.ISO  -> disco 2 com falas e textos traduzidos
HARVEST_CD\HARVESTER_DISC3.ISO  -> disco 3 com falas e textos traduzidos
INSTALAR.bat / INSTALAR.ps1     -> instala sozinho (recomendado)
RESTAURAR.bat / RESTAURAR.ps1   -> volta os arquivos originais
FERRAMENTA\                     -> ferramenta e planilhas da tradução (só se precisar refazer)

As legendas ficam em português; as vozes continuam em inglês.
Para ver as legendas, a opção TEXTO do menu de opções precisa estar ligada.


Onde fica a pasta do jogo
-------------------------
Na Steam: clique com o botão direito em Harvester > Gerenciar > Explorar arquivos locais.
Normalmente é:
    C:\Program Files (x86)\Steam\steamapps\common\Harvester
Dentro dela existem as pastas HARVEST e HARVEST_CD (e dosbox_windows).


JEITO FÁCIL (recomendado)
-------------------------
1. Feche o jogo.
2. Dê dois cliques em INSTALAR.bat.
3. Digite a pasta do jogo (ou só aperte Enter se for o caminho padrão acima).
4. Ele confere se os seus arquivos são a mesma versão, guarda os originais em
   <pasta do jogo>\BACKUP-ORIGINAL-PTBR e copia os traduzidos.
   Conferir as ISOs demora um pouco; espere a mensagem verde.
5. Abra o jogo pela Steam normalmente.

Para desfazer: dois cliques em RESTAURAR.bat.


JEITO MANUAL (se preferir)
--------------------------
1. Feche o jogo.
2. Faça uma cópia de segurança dos 6 arquivos originais (lista abaixo).
3. Copie, substituindo:
     PATCH\HARVEST\DIALOG.RSP              ->  <pasta do jogo>\HARVEST\DIALOG.RSP
     PATCH\HARVEST\MENU.INI                ->  <pasta do jogo>\HARVEST\MENU.INI
     PATCH\HARVEST\HARVEST.EXE             ->  <pasta do jogo>\HARVEST\HARVEST.EXE
     PATCH\HARVEST_CD\HARVESTER_DISC1.ISO  ->  <pasta do jogo>\HARVEST_CD\HARVESTER_DISC1.ISO
     PATCH\HARVEST_CD\HARVESTER_DISC2.ISO  ->  <pasta do jogo>\HARVEST_CD\HARVESTER_DISC2.ISO
     PATCH\HARVEST_CD\HARVESTER_DISC3.ISO  ->  <pasta do jogo>\HARVEST_CD\HARVESTER_DISC3.ISO
   (PATCH = esta pasta)
4. Abra o jogo pela Steam.


Cuidados
--------
- NÃO use "Verificar integridade dos arquivos" na Steam: ela troca os arquivos de volta
  para o inglês. Se isso acontecer, é só rodar o INSTALAR.bat de novo.
- Saves antigos continuam funcionando (a tradução não muda a lógica do jogo).
- O HARVEST.EXE traduzido só serve para a mesma versão do jogo. Por isso o instalador
  confere os arquivos antes de copiar.


Se a versão for diferente
-------------------------
Se o INSTALAR.bat disser "VERSAO DIFERENTE", nada foi alterado. Nesse caso a tradução pode
ser gerada a partir dos SEUS arquivos (precisa do Python 3 instalado), abrindo o PowerShell
dentro da pasta FERRAMENTA:

    python harvester_texto.py aplicar --traducao TRADUCAO --jogo "<pasta do jogo>\HARVEST" --isos "<pasta do jogo>\HARVEST_CD" --saida NOVO-PATCH

Ela valida tudo antes e cria NOVO-PATCH\HARVEST e as 3 ISOs traduzidas, sem mexer no jogo.
Se a versão for muito diferente, ela avisa quais textos não bateram.

Ao testar, anote
----------------
- texto ainda em inglês (onde apareceu);
- texto saindo da caixa;
- tópico de conversa que não responde direito;
- qualquer travamento (e o que estava fazendo).
